# TechLab website

RAM and SSD upgrades for PS5, PC and laptops in Lebanon.

## Put it online with GitHub Pages

1. Create a new public repository on GitHub, for example `techlab`.
2. Click **Add file → Upload files** and drag in everything from this folder: `index.html`, `README.md` and the whole `img` folder. Click **Commit changes**.
3. Go to **Settings → Pages**. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick the `main` branch and the `/ (root)` folder, then **Save**.
4. Wait a minute or two. Your site is live at `https://YOUR-USERNAME.github.io/techlab/`.

## Editing

- WhatsApp number: search `96171127767` in `index.html`.
- GTA 6 countdown date: search `Date.UTC(2026, 10, 18, 22` (that is 19 November, midnight Beirut time).
- Images live in the `img` folder. Keep the same file names when you replace one.
